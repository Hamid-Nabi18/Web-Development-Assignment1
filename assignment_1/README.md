# Assignment 1 - Web Development & Design
Topics: HTML, CSS, JavaScript
Deadline: November 7th, 2026
Submission: LMS Portal

## Project Structure & 16 Required Tasks

### PART 1: FOUNDATIONAL TASKS
1. **task-01-artisan-coffee-shop** — Artisan Coffee Shop Landing Page (Semantic HTML & responsive CSS Grid menu)
2. **task-02-dynamic-quiz** — Dynamic Multiple-Choice Quiz (Array of question objects, choice coloring, input locking, running score)
3. **task-03-todo-manager** — To-Do List & Task Manager (Full CRUD, LocalStorage persistence, category filters)
4. **task-04-saas-pricing** — SaaS Subscription Tiers (CSS Flexbox 3-tier pricing table, highlighted Professional tier)

### PART 2: INTERMEDIATE TASKS
5. **task-05-faq-accordion** — Expandable Help Center Panel (Smooth expansion, enforced single-item accordion collapse)
6. **task-06-profile-tabs** — Profile Settings Dashboard Tabs (Modular tabs, active styling, WAI-ARIA tablist & keyboard navigation)
7. **task-07-newsletter-modal** — Newsletter Sign-Up Overlay (Centered modal, backdrop dimming, scroll locking, 3-way dismissal)
8. **task-08-feedback-monitor** — Feedback Text Area Monitor (Live character counter, warning states, RFC 5322 email validation)

### PART 3: ADVANCED TASKS
9. **task-09-flash-sale-carousel** — Flash Sale Timer & Carousel (Live countdown interval loop, responsive product carousel with controls & pagination)
10. **task-10-notes-quote-generator** — Notes App & Quote Generator (Dual-pane Markdown previewer, random quote widget with clipboard copying)
11. **task-11-trello-kanban** — Trello-Style Workflow Manager (HTML5 Drag & Drop APIs, immutable state management, browser storage persistence)
12. **task-12-infinite-scroll-search** — Search Filter & Infinite Scroll (5,000 simulated records, debounced search, Intersection Observer streaming)
13. **task-13-rich-text-workspace** — Rich Text Workspace Suite (XSS content sanitization, Command Pattern undo/redo history stack)
14. **task-14-canvas-drawing-suite** — Interactive Canvas Drawing Suite (HTML5 Canvas freehand, shapes, color pickers, clear, undo, PNG export)
15. **task-15-multi-step-onboarding** — Multi-Step Form with Schema Validation (Multi-stage wizard, progress indicators, schema rules, global cache)
16. **task-16-wcag-combobox-router** — WCAG Combobox & Custom Router (W3C WCAG 2.1 AA combobox, vanilla JS client-side SPA router with path params)

## How to Run Any Task
Each task is completely self-contained with its own `index.html`, `style.css`, and `script.js`. Simply open the `index.html` of any task folder directly in any modern web browser!
